# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of IAPEX seriously. If you discover a security vulnerability, please report it privately.

**Do not** disclose security vulnerabilities publicly via GitHub issues.

Send details to: christian.serrano.puertos@gmail.com

You should receive a response within 48 hours. If not, please follow up.

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We appreciate your help in keeping IAPEX secure.
